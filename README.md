# ברזל לברזל – דף נחיתה

דף נחיתה למסגרייה "ברזל לברזל – מכניקה הנדסית", אזור התעשייה בני יהודה, רמת הגולן.

- קובץ אחד: `index.html` (+ `accessibility.html`), בלי שלב בנייה.
- הפניות נשלחות כהודעת וואטסאפ ל־054-2344193. שום מידע לא נשמר בשרת.
- פרמטרי `utm_source` / `utm_campaign` בקישור נוספים אוטומטית להודעת הוואטסאפ.
- אירועי המרה (`whatsapp_click`, `call_click`, `lead_form`) נשלחים ל־`dataLayer`, מוכנים ל־Google Tag Manager / Meta Pixel.
- סרטוני הסדנה: Pexels (רישיון חינמי לשימוש מסחרי), עובדו לגוון וינטג'. להחלפה בצילומים אמיתיים מהסדנה.
